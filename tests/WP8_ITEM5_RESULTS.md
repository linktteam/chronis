# WP8 Item 5: two channels (results)

Labels: RUN = executed in this container and the output is in `wp8_evidence/`; READ = read in code or docs; UNKNOWN = not established.
No evaluation seed was touched. This item has no fit-based study: its tests use synthetic summaries (physical means drawn by `data/synthetic_identity.py`, synthetic context profiles). A real contextual channel is **UNKNOWN**: no real descriptors exist here and none were built.

## What was built (READ)
- Channel 1 (physical): regime means in real units with the stored scaler of every fit; readable through the feature registry (`lineage.regime_table`: name, unit, source, role, direction). Unchanged from Item 4.
- Channel 2 (contextual, optional): the caller supplies one non-negative profile per regime that sums to 1 (`FitSummary.context_profiles`; `lineage.validate_context_profiles`, `context_profiles_from_days` aggregates daily proportions by the decoded regime). Distance = squared Hellinger (`hellinger2_matrix`, in [0, 1]). No topic or scene extraction was built; nothing reads raw conversations or images.
- Combined cost `w1 * D1 / s1 + w2 * D2 / s2`, `s` = the anchor's mean pairwise inter-regime distance in that channel (1.0 if it is zero or K < 2). Default `ChannelConfig(w1 = 1, w2 = 0)` = channel 1 alone, **bit for bit** (test).
- Disagreement rule (owner decision A6, declared in `tests/PREDECLARED_CRITERIA_WP8.md` 4.5): if each channel alone gives a confident alignment (its own margin above its **own** threshold) and the two assignments differ, the state is `CONTINUITY_UNVERIFIED` with reason `channels_disagree`; the old names stay and the message says "cannot confirm this is the same as before". A channel that is not confident cannot veto the other. A missing profile falls back to channel 1 and the record says so (`channels_used`, `channel_detail`). A mismatch in the number of context categories is a `ValueError`.
- Contract (`docs/INTEGRATION_CONTRACT_HSSM.md` 9.10): contextual descriptors are sensitive personal data and must come from a consented, aggregated, non-identifying pipeline.

## Tests and mutants (RUN)
- `tests/test_wp8_item5_channels.py`: **26 tests** (Hellinger formula, symmetry, 0 and 1 cases; profile validation; daily aggregation; channel 1 readable in physical units; weight validation; default weight = channel 1 bit for bit; missing profile fallback; category mismatch; context decides when the physical channel cannot; physical channel decides when the context is silent; two confident channels that disagree -> CONTINUITY_UNVERIFIED for several weight pairs; an unconfident channel cannot veto; weights decide when only one channel is confident; K change stays K_CHANGED; JSON-ready record and PENDING status; declared scales; each channel's own scale and its own threshold; anchor profiles follow stable names, not raw order; channel information survives NEW_NAMES; the consent statement in the contract; after the Item 4 freeze: two agreeing channels cannot rescue a class of pair without a calibrated threshold).
- Mutants: **25 of 25 killed** (`wp8_evidence/item5_mutation_results.txt`, `integration_report/wp8/scripts/mutation_item5.py`). Re-run on 2026-11-25 after the Item 4 freeze (the item was first made against provisional defaults; the code now carries the frozen ones, `C25` is new). Eight were first missed in the first run and led to new tests (scale-sensitive example, own-threshold test, stable-name anchor test, negative sum-1 profile, daily-count aggregation, the no-descriptor message, NEW_NAMES channel info).
